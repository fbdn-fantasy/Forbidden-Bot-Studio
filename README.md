# Forbidden Bot Studio 💜

**Free, offline character creation for LusyChat, LiL, SpicyChat, CrushOn and CraveU.**

Forbidden Bot Studio is a free, offline character editor for LusyChat, LiL, SpicyChat, CrushOn and CraveU. Create site-specific JSON files or embed character details into PNG images, with character limits, counters and saved drafts. Open it in your browser and start creating. No installation or account needed.

## Features

- **Five supported platforms:** LusyChat, LiL, SpicyChat, CrushOn and CraveU.
- **Site-specific JSON export:** Automatically maps your character fields to the selected platform's format.
- **PNG with JSON:** Embed character information into PNG metadata for platforms that support character-card imports.
- **Character-limit checks:** Site-specific field limits, live counters and estimated token counts.
- **Drafts and imports:** Save a portable draft, load supported JSON/draft files, and switch destinations without losing editor text.
- **Offline and private:** Character editing and export happen locally in your browser; no account or installation required.

## Getting started

1. Download `Forbidden-Bot-Studio-Free-V4.html` from this repository.
2. Open the downloaded file in a modern web browser.
3. Select **Create JSON** or **PNG with JSON**.
4. Choose your destination platform, fill in your character details and export.

> **Tip:** Use **Save draft** to keep a portable backup. Browser autosave may be lost if you move the HTML file, change browsers or clear browser data.

## Supported formats

| Platform | JSON export | PNG with embedded JSON |
| --- | --- | --- |
| LusyChat | Yes | Available; platform import support may vary |
| LiL | Yes | Available; platform import support may vary |
| SpicyChat | Yes | Available; platform import support may vary |
| CrushOn | Yes | Available; platform import support may vary |
| CraveU | Yes | Available; platform import support may vary |

SpicyChat uses separate **Title** and **Character Name** fields. Other sites also differ in field names and limits; the editor applies the selected site's mapping automatically. PNG embedding accepts PNG files only, not JPG or WebP.

## Privacy

Character text is processed locally by the app. Sharing the HTML application does not include your browser-saved draft. **Exported JSON files, drafts and PNG character cards do contain character data**, so review them before sharing.
