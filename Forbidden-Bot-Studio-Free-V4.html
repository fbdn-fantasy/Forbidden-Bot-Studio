Using this app
Open this HTML file in your browser, enter your character, then choose Generate .json. Upload the downloaded JSON to your bot site's character importer.
The current draft is automatically saved in this browser when storage is available. Moving the HTML file, changing browsers or clearing browser data can lose that copy. Use Save draft for a reliable file backup.
JSON imports detect this app’s mapping marker, known filename suffixes and legacy fields automatically. Unmarked files default to LusyChat mapping; always check the loaded introduction and personality. Draft files from either older generator load correctly regardless of source. Load JSON / draft accepts flat character JSON and V2-style cards. Imported files only load the six editor fields; other metadata is not retained.
